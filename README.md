# kk蛋糕店预约网页

这是一个手工蛋糕店预约网页初版，包含店铺介绍、预约表单、门店位置和真实风格店铺照片展示。

## 预览方式

直接用浏览器打开 `index.html` 即可预览页面。

## 项目结构

```text
.
├── assets/
│   ├── cake-class.png
│   ├── interior.png
│   └── storefront.png
├── index.html
├── script.js
├── styles.css
├── .gitignore
└── README.md
```

## 主要功能

- 预约登录手机号、联系人姓名和联系电话
- 选择预约日期、时间段和体验人数
- 填写备注需求
- 提交后显示预约确认提示
- 展示店铺简介、位置、门店照片、店内环境和教学场景
